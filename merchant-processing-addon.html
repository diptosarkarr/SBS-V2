Common Questions

Frequently Asked Questions

Everything you need to know about the Merchant Processing Add-On.

What's included in the Merchant Processing Add-On? +
The Merchant Processing Add-On is $1,000 one-time, and adds merchant processing to any existing website.
Do I need a specific type of website for this add-on? +
No specific platform is required — this add-on requires an existing website, but works with any existing website.
Can I add this to my WooCommerce store? +
Yes. Since it works with any existing website, it can be added to an existing WooCommerce store. See our WooCommerce Stores page if you don't have a WooCommerce site yet.
Is this a one-time or recurring cost? +
Sites by Sara's $1,000 fee is one-time, covering the setup and integration. Your payment processor's own transaction fees are billed separately by them.
What if I don't have a website yet? +
This add-on requires an existing website. If you don't have one yet, see our Custom WordPress Development, Static HTML Sites, or WooCommerce Stores pages to get one built first.
Does adding merchant processing require rebuilding my website? +
No. This is an add-on to your existing website, not a rebuild.
