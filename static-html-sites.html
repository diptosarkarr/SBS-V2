Common Questions

Frequently Asked Questions

Everything you need to know about our Static HTML Site builds.

What's the difference between the 1-Page and 5-Page Static Site? +
Both are fully static sites with no CMS and no database. The 1-Page Static Site has 3–5 sections and up to 1,500 words on a single page, for $650 one-time. The 5-Page Static Site splits your content across up to 5 separate pages, for $850 one-time.
Can I add more pages later? +
Yes. Additional Pages are available at $500 one-time per block of 5 pages beyond the base 5-page site. If you start with the 1-page tier, you'd move up to the 5-Page Static Site first, then add further blocks of 5 pages from there.
Is a Static HTML Site the same as your Simple Squeeze Page Sites service? +
Yes, they're built from the same underlying static, no-CMS site tiers. This page is for a general static website — a brochure, portfolio, or informational presence. If you specifically want a single-page marketing or lead-capture design, see our Simple Squeeze Page Sites page instead.
Why choose a static HTML site instead of WordPress? +
A static HTML site has no CMS and no database — there's no dashboard, no login, and no plugins to keep updated. That means less to maintain and less attack surface. If you'd rather edit your own content, publish a blog, or grow into e-commerce down the road, our Custom WordPress Development service is built around a full content management system instead.
What hosting options are available for a Static HTML Site? +
Two options: Domain Renewal & Hosting at $25/mo, which covers domain reservation and hosting for non-WordPress, simple HTML sites; or WHAM Hosting & Maintenance's Squeeze Page tier at $75/mo (or $855/yr, 5% off), which adds ongoing maintenance and is scoped to a 1-page squeeze site.
Will my Static HTML Site be mobile-friendly? +
Yes. Every site we build, including Static HTML Sites, is designed mobile-first and tested across desktop, tablet, and phone screens before launch.
