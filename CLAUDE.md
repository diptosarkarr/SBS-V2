# SBS-V2 working rules

Before editing ANY service landing page (anything in the all-services directory, e.g. `local-seo-services.html`),
read `SERVICE-PAGE-GUIDELINES.md` in full and finish by running
`python scripts/check_service_page.py <page>.html --check-ids` (must report 0 errors) and ticking the checklist in section 8.

Also read `design.md` (look) and `build-guide.md` (process). The guideline file wins on what page copy may say.
